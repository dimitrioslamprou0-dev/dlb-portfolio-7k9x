Sync portfolio data across all your devices. Uses a private GitHub Gist (only you can see it). Create token → Required: "Gists" permission (Read & Write).
Setup instructions
  1. Click "Create token →" above
  2. Name it (e.g. "Portfolio Terminal")
  3. Expiration: pick how long you want (or "No expiration")
  4. Account permissions: leave alone
  5. Scroll to Gists → set to "Read and write"
  6. Click "Generate token", copy it (starts with github_pat_)
  7. Paste it below, click "Connect & Save to Gist"
  8. The dashboard creates a private gist and remembers the ID
  9. On other devices: paste same token + paste Gist ID → "Load from Gist"
